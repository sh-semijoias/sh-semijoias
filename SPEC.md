# Configurar conexão com banco de dados
## Tecnologias utilizadas
- Postgresql;
- EF Core;
- ASP.NET Core Identity;
- Migrations;

## Usuários
Só são necessárias as entidades de Usuario e Perfil. Use tabelas customizadas com nomes em português;
Crie um usuário administrador, se não existir, ao inicializar a aplicação;

## Escopo
O escopo dessa alteração é o backend apenas;
